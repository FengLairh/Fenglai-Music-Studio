# Product showcase

[English README](../README.en.md) · [简体中文](SHOWCASE.zh-CN.md)

Real desktop screenshots captured with isolated demonstration drafts. Models are not installed in this demo environment, so some generation controls are disabled. These images show the interface, not a synthesis-quality evaluation. UI labels are currently Chinese.

## Composition
A shared workspace for the creative theme, lyrics, style and notation. AI assistance lives within each field; notes and lyrics can be edited on the score.

![Composition](showcase/create.png)

## Song covers
Choose style/lyric adaptation, lyrics-only, or lyrics-and-score editing. Import audio to select a waveform region and extract a score.

![Song covers](showcase/cover.png)

## Voice covers
Choose voice presets or an uploaded reference voice, then manage conversion and reference settings in the same workspace.

![Voice covers](showcase/voice.png)

## Lyric listening view
Click the track information at the bottom left to reveal an upward-sliding lyric view. The seek bar sits along the player’s top edge and shows a handle and time on hover. Reliably timed lyrics follow playback and support click-to-seek.

![Lyrics](showcase/lyrics.png)

## Settings
Themes, backgrounds, GPU selection and local environments are managed together. Installed components show status, while missing components expose installation actions.

![Settings](showcase/settings.png)

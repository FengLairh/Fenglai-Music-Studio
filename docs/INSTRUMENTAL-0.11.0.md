# 0.11.0 · 官方纯音乐流程

音乐创作与歌曲 Cover 增加「输出类型」：歌曲 / 纯音乐。纯音乐不会演唱歌词框内容，切换模式不会清除原歌词草稿。

- 已有乐谱：使用官方转轨工具，把 Vocal 旋律移入 Ins 并校验音高、起音、时值及节拍。
- 没有乐谱：先调用现有 YuE2 符号规划器，再转轨生成；空白或截断规划直接报错，不替换成其他旋律。
- 默认重新配伴奏，可勾选「保留参考和声」。纯音乐模式不适用「只改词」分类。
- 音频 Cover 继续使用本地波形选段、SheetSage2 提谱与串行单卡队列，转换后重新生成音乐，不提取原伴奏波形。
- 转轨检查保存在作品 artifacts/instrumental-transfer.json；原始参考谱保存在 original.abc。

官方 Skill 更新至 yue2-music-v1.2.0（72272f907522dcca2e97c848d6c8f0d343999183），包含 42 个经过哈希记录的文件；新增 instrumental 子目录辅助脚本保留 MIT 许可。现有 YuE2 0.1.6 引擎、模型权重与 Windows torch-eager 单卡运行方式保持原版本。

验证：102 项 Node 测试、官方工具套件、适配器规划/参考转轨测试、桌面模式切换与草稿恢复测试。真实本地 GPU 参考谱生成输出 49.7587 秒 / 48kHz，模型报告未截断；16 个旋律音符转轨后逐项保留。自动写谱路径通过适配器模拟测试，未新增一次完整 GPU 写谱验收。音质、是否出现人声及实际音频是否忠于谱面未作人工听音验收，生成时长不保证等于乐谱时长。
